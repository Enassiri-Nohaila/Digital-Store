💻 Digital Store

Votre boutique de matériels informatiques

📌 Description

Digital Store est un projet web réalisé avec React.js. Il présente une boutique de matériels informatiques et d'accessoires à travers une interface simple et moderne.

Ce projet a été développé dans le cadre de mon apprentissage de React.js et du développement Front-End.

✨ Structure du projet

L'application est organisée en plusieurs composants React :

- Header
- Navbar
- Main
- Sidebar
- Footer

🛠️ Technologies utilisées

- React.js
- JSX
- CSS3
- HTML5

🎯 Objectifs du projet

- Découvrir React.js.
- Comprendre le fonctionnement des composants.
- Apprendre à organiser une application React.
- Pratiquer la création d'interfaces web avec JSX et CSS.

🚀 Installation et lancement

1. Cloner le repository :
   
   git clone URL_DU_REPOSITORY

2. Accéder au dossier :
   
   cd digital_store

3. Installer les dépendances :
   
   npm install
   
4. Lancer l'application :
  
5. npm start
